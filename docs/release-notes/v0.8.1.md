# Saffron Drift v0.8.1

A fix for the Tester tools. Builds 0.7.3 and 0.8.0 shipped without the Tester tools code check, so the Tester tools in Settings would not open. Play was not affected.

## Five minute test

1. Install the APK over v0.8.0. Your saves stay.
2. Open Settings, then Tester tools. Enter your code. The tools open.

## Fixed

- The Tester tools open again (G5.9). The build step that adds the code check was missed in 0.7.3 and 0.8.0.

## Shared kit

Kit 1.15.0, unchanged. Godot 4.7.2.

## Install

Version 0.8.1 installs over 0.8.0 and keeps your saves.

## Test checklist

- [ ] Tester tools open with your code.
