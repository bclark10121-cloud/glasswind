# Saffron Drift

A calm magic carpet ride across a quiet desert basin. Android and browser. Named Glasswind until 0.7.1.

- Play and download: https://bclark10121-cloud.github.io/saffron-drift/
- `docs/` is the GitHub Pages site: the page at the root, the game in `docs/play/`, APKs in `docs/downloads/`, release notes in `docs/release-notes/`.
- Source lives in a private studio repo. This repo holds only the page and builds.
